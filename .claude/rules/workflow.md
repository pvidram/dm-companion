# Workflow with the agent

- Always plan before coding. Propose the plan and wait for approval.
- Make no changes outside the requested scope.
- If something fails, diagnose the root cause before changing approach.
- Explain decisions: what is done, why, and which alternatives were discarded.
- Atomic commits: one commit = one logical change.

## Checklist when closing a feature

1. Tests updated and passing (`testing.md`).
2. Project documentation updated (README, public API comments).
3. Lint and typecheck green.
4. Working tree clean or containing only related changes.
